Iris Flower Classification Using Machine Learning
Project Overview
This project focuses on exploring the Iris dataset and applying machine learning algorithms to classify iris flowers into three species: Setosa, Versicolor, and Virginica.
The project demonstrates how different classification algorithms learn patterns from data and make predictions.
Objectives
Explore and understand the Iris dataset.
Perform basic data analysis and visualization.
Build classification models.
Visualize logistic regression decision boundaries.
Machine Learning Algorithms
Logistic Regression
Decision Tree Classifier
Tools and Libraries
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Jupyter Notebook
Model Evaluation
The models are evaluated using:
Accuracy
Precision
Recall
F1-score
Confusion Matrix
Project Structure
Iris_Classification.ipynb – Jupyter Notebook containing the analysis, model development, visualizations, and evaluation.
Conclusion
This project provides practical experience in classification, model evaluation, and decision boundary visualization using machine learning.
